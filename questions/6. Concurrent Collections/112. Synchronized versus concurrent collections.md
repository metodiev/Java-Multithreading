# 112. What is the difference between synchronized collections and concurrent collections?

> **Section:** 6. Concurrent Collections · **Level:** Practitioner to architect

## TL;DR

Synchronized wrappers serialize methods; concurrent collections support finer-grained access.

## How it works

Synchronized wrappers typically serialize each method using one mutex; iteration still requires external synchronization around the entire traversal. Concurrent collections use data structures and finer-grained coordination designed for concurrent access. Select by required atomicity: a wrapper can be adequate for simple low-contention state.

## Example

```java
Map<String, Integer> map = Collections.synchronizedMap(new HashMap<>());
```

## Architect insight

Select based on required atomicity, contention, and traversal semantics.

## Common pitfall

Individual thread-safe calls do not make a multi-call workflow atomic.

# 106. When should you use CopyOnWriteArrayList?

> **Section:** 6. Concurrent Collections · **Level:** Practitioner to architect

## TL;DR

Use for small, read-mostly lists where stable iteration matters more than immediate freshness.

## How it works

Use it for small, read-mostly collections where iteration greatly outnumbers mutation, such as listener registries. It provides simple snapshot iteration without reader coordination. Avoid it for large lists or frequent writes, and remember iterators are stale snapshots rather than live views.

## Example

```java
listeners.add(listener); for (Listener listener : listeners) listener.onEvent(event);
```

## Mermaid diagram

```mermaid
flowchart LR
    A[Rare membership writes] --> B[Copy on mutation]
    B --> C[Stable iteration]
```

## Architect insight

Measure list size, write rate, and acceptable staleness before choosing it.

## Common pitfall

An iterator is not a live view and does not see subsequent additions.

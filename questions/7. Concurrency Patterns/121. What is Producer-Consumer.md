# 121. What is the Producer-Consumer pattern?

> **Section:** 7. Concurrency Patterns · **Level:** Practitioner to architect

## TL;DR

Producer-consumer decouples work creation from processing through a handoff.

## How it works

Producers create work and consumers process it through a handoff mechanism, decoupling their rates and lifecycles. A queue can buffer bursts; a bounded queue makes capacity and overload behavior explicit. Define shutdown, poison/end-of-stream signaling, delivery guarantees, and what happens to queued work on failure.

## Example

```java
BlockingQueue<Job> jobs = new ArrayBlockingQueue<>(100);
```

## Mermaid diagram

```mermaid
flowchart LR
    A[Producers] --> B[Handoff queue]
    B --> C[Consumers]
```

## Architect insight

Define enqueue, completion, failure, and shutdown as one lifecycle protocol.

## Common pitfall

Unbounded buffering delays overload and risks exhausting memory.

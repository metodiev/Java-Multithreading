# 133. What is a thread confinement pattern?

> **Section:** 7. Concurrency Patterns · **Level:** Practitioner to architect

## TL;DR

Thread confinement assigns mutable state to one thread, avoiding concurrent access.

## How it works

Thread confinement gives mutable state to one thread and prevents other threads from accessing it. This avoids synchronization for that state; examples include local variables and carefully scoped thread-local state. Thread pools reuse workers, so thread-local values must be cleared to prevent leaks and cross-request data contamination.

## Example

```java
try { context.set(requestContext); handle(); } finally { context.remove(); }
```

## Mermaid diagram

```mermaid
flowchart LR
    A[Owning thread] --> B[Confined mutable state]
    B --> C[No concurrent access]
```

## Architect insight

Prefer explicit parameters when practical; always clean thread-local values on pooled workers.

## Common pitfall

Worker reuse can leak thread-local state across requests.
